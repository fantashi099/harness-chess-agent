How the node budget works

One shared limit for choosing a White move. Search, verification and safety checks all spend from it. The budget resets on the next White turn.

A node counts a visit to a hypothetical position, not a unique board. Deeper searches and separate verification can revisit the same position.

Example with 6,000 nodes: in LLM + Tools, up to 3,000 for broad search, 2,000 protected for verification, and 1,000 reserved for comparison. These are limits and reserves, not fixed spending; unused nodes remain available.

Depth is separate. Depth 4 targets White–Black–White–Black. If nodes run out, the last completed depth is retained. Quiescence may extend captures, promotions and check evasions, using the same budget.

This does not limit LLM tokens, elapsed time or Stockfish’s search. LLM + Tools shows usage after the turn’s final verification. Tools Only shows total usage for that turn’s search.
